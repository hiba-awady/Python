# Smart Calculator

A command-line calculator built with Python.

## Features

* Addition
* Subtraction
* Multiplication
* Division
* Power
* Percentage
* Square Root
* History System
* Search Operations
* Delete Last Operation
* Statistics
* Operation Counter
* Timestamps for saved operations

## Project Structure

* `main.py` → Program entry point
* `operations.py` → Mathematical operations
* `history.py` → History management
* `utils.py` → Input validation
* `history.txt` → Stored operations

## How to Run

```bash
python main.py
```
